# DAY SIX CHALLENGES
## Dimension vs Fact Table
| Fact | Dimension |
| --- | ----------- |
| Attributes | Attributes |
| Quantitative data (measurable data) about business process e.g sales amount| Descriptive data attributes for facts such as product info |
| Transactional data or aggregated data (Contains foreign keys) referencing dim tables| Textual entities/ categorical one row per product |
| Bigger as data changes frequently| Smaller as data remains relatively stable with infrequent chnages |
